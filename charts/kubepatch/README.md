# Kubepatch

[Kubepatch by AppsCode](https://github.com/appscode-cloud) - Patch console and AKP v2 behind one host

## TL;DR;

```bash
$ helm repo add appscode https://charts.appscode.com/stable/
$ helm repo update
$ helm search repo appscode/kubepatch --version=v2026.11.15
$ helm upgrade -i kubepatch appscode/kubepatch -n kubepatch --create-namespace --version=v2026.11.15
```

## Introduction

This chart deploys a Kubepatch on a [Kubernetes](http://kubernetes.io) cluster using the [Helm](https://helm.sh) package manager.

## Prerequisites

- Kubernetes 1.29+
- A default StorageClass (or set persistence.storageClassName)
- Gateway API and a Gateway controller (or an Ingress controller with routing.mode=ingress)

## Installing the Chart

To install/upgrade the chart with the release name `kubepatch`:

```bash
$ helm upgrade -i kubepatch appscode/kubepatch -n kubepatch --create-namespace --version=v2026.11.15
```

The command deploys a Kubepatch on the Kubernetes cluster in the default configuration. The [configuration](#configuration) section lists the parameters that can be configured during installation.

> **Tip**: List all releases using `helm list`

## Uninstalling the Chart

To uninstall the `kubepatch`:

```bash
$ helm uninstall kubepatch -n kubepatch
```

The command removes all the Kubernetes components associated with the chart and deletes the release.

Specify each parameter using the `--set key=value[,key=value]` argument to `helm upgrade -i`. For example:

```bash
$ helm upgrade -i kubepatch appscode/kubepatch -n kubepatch --create-namespace --version=v2026.11.15 --set global.platform.host=kubepatch.example.com
```

Alternatively, a YAML file that specifies the values for the parameters can be provided while
installing the chart. For example:

```bash
$ helm upgrade -i kubepatch appscode/kubepatch -n kubepatch --create-namespace --version=v2026.11.15 --values values.yaml
```

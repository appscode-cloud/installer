{{- if eq .Values.tls.mode "selfSigned" }}

The certificate is self-signed: a browser warns, `curl` needs -k.
{{- end }}

The generated credentials are in Secret {{ include "kubepatch.credentialsSecret" . }}. The first administrator is
Casdoor user "{{ .Values.casdoor.admin.username }}"; its password is the key `admin-password`:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "kubepatch.credentialsSecret" . }} -o jsonpath='{.data.admin-password}' | base64 -d

The patch console reads AKP's clusters with an iam API token. Make one as that administrator, then:

  kubectl -n {{ .Release.Namespace }} create secret generic {{ include "kubepatch.fullname" . }}-akp-token --from-literal=token=<token>
  helm upgrade ... --set patchConsole.akp.tokenSecret={{ include "kubepatch.fullname" . }}-akp-token
